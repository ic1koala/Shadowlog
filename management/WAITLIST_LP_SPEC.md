## 1. 開発目的と背景

11月の正式リリースに向け、VIPテスター以外の一般英語学習者（Threads、SNS、紹介経由の訪問者）に対して、ShadowLogの魅力とコア価値を伝え、事前登録者（リード顧客）を獲得する専用LP（`/waitlist`）を新設する。  
未完成なベータ版体験による離脱を防ぎ、完成度の高いLPで「14日間無料体験クーポン」をインセンティブとして提供し、ローンチ初日から熱量の高い顧客基盤を構築する。

### ② 動くインタラクティブUIデモ（案A）
- コード（React + CSS）で動く超軽量・高画質なシャドーイング実況シミュレーション。
- 内容:
  1. お手本音声の再生波形アニメーション
  2. ユーザーの発声認識シミュレーション
  3. **音声AIによるリアルタイム色分け判定**:
     - 正しく発音できた単語（緑色）
     - 読み飛ばし・発音のズレがあった単語（赤色ハイライト）
  4. 発音スコア（例: 94%）と話速WPM（例: 138 WPM）がパッと表示される演出。

### ③ お悩み共感セクション
- **タイトル**: こんなお悩み、ありませんか？
- **項目**:
  - 🗣️ **声に出す機会がない**: 日常生活や仕事で英語をアウトプットする場がほとんどない
  - 🤔 **合っているか分からない**: 一人でシャドーイングしても、正しく発音できているか客観的に判断できない
  - 💸 **コーチングは高すぎる**: 月額2〜3万円するスクールやコーチングサービスは継続が厳しい

### ④ ShadowLogの3大特徴（解決策）
1. **音声AIによるリアルタイム色分け判定**:
   - 言えていない単語や読み飛ばしを1単語単位で瞬時に色分け可視化。自分の発音のクセがひと目でわかります。
2. **話速（WPM）と発音スコアの見える化**:
   - 1分間の発話単語数（WPM）と正解率を記録。ネイティブスピードへの到達度が可視化され、成長を実感できます。
3. **続けやすい価格設定（月額500円〜）**:
   - 高額な人件費をAIで自動化。カフェ1杯分の手軽な価格で、毎日無理なく英語を発する習慣を作れます。

### ⑤ 料金プラン予告（透明性）
- **Free**: 気軽にお試し体験
- **Basic（月額500円）**: 短文シャドーイング無制限（使い放題）
- **Pro（月額1,480円）**: 長文スピーチ・WPM詳細解析・AIコーチレビュー
- *注記: 事前登録いただいた方全員に、リリース時に「14日間無料体験クーポン」をプレゼント！*

## 4. メール登録後の動作仕様

### ① 画面上の挙動
- 登録完了後、フォームが即座に「🎉 **事前登録が完了しました！**」カードに切り替わる。
- 登録完了メッセージ:
  > ご登録いただいたメールアドレスへ確認メールをお送りしました。11月の正式リリース日に、14日間無料体験クーポンコードと一緒にお知らせいたします。

### ② Resendによる自動返信メール
- **送信元**: `ShadowLog 運営事務局 <noreply@resend.dev>`（または設定済み送信元）
- **件名**: `【ShadowLog】事前登録ありがとうございます（14日間無料体験クーポン付き）`
- **本文**:
  ```text
  ShadowLogのウェイティングリストにご登録いただき、誠にありがとうございます。

  私たちは「気軽な価格で、生活に英語を発する機会を。」をテーマに、最新の音声AIを活用した次世代シャドーイング習慣化アプリを開発しています。

  2026年11月の正式リリース日に、アプリのご案内とともに【14日間無料体験クーポンコード】をお届けいたします。

  リリースまで楽しみにお待ちいただけますと幸いです。

  ──────────────────────
  ■ 特典内容: 正式リリース時 14日間無料体験クーポン
  ■ リリース予定: 2026年11月
  ──────────────────────
  ※本メールに心当たりがない場合や登録解除をご希望の場合は、本メールへご返信ください。
  ShadowLog 開発チーム
  ```

### ③ データ永続化（Supabase）
- テーブル名: `public.waitlist_subscribers`
  - `id`: UUID (PK)
  - `email`: TEXT NOT NULL UNIQUE
  - `status`: TEXT NOT NULL DEFAULT 'pending'
  - `created_at`: TIMESTAMPTZ NOT NULL DEFAULT NOW()
  - `metadata`: JSONB (IP、ユーザーエージェント、UTMパラメータ等)
- 重複登録時はエラーにせず「すでにご登録いただいております」としてサンクスメール再送または正常完了。
