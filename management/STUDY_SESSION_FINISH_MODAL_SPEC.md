## 1. 目的と背景

- **課題**: 練習終了時の明示的な「区切り・クロージング」が存在せず、1回の学習の達成感や成長の実感が得られにくい状態だった。
- **解決策**:
  - 採点結果画面の下部バー（「次のフレーズへ」ボタンの左横）に **`[ 🏁 今日の学習を終了 ]`** ボタンを新設。
  - タップすると、**「本日の学習時間」「連続学習ストリーク」「AIコーチの温かい労い」「今回の復習ポイント」** をまとめたシンプルで洗練されたサマリーモーダルを表示。
  - さらに、ユーザーの自己肯定感を高めると同時に自然な口コミ流入を生む **「X / Threads / Instagram」へのSNSシェア機能** を提供する。

## 3. 「勉強終了窓（サマリーモーダル）」の仕様

### 3.1 構成要素（シンプル重視）
新規コンポーネント: `src/components/features/practice/StudySessionSummaryModal.tsx`

1. **ヘッダー**:
   - `🎉 今日のシャドーイング完了！`
   - サブテキスト: `お疲れ様でした、素晴らしい集中力です！`
2. **スタッツカード（2カラム）**:
   - **⏱️ 本日の学習時間**: セッション開始時からの経過時間（例: `8分24秒`）
   - **🔥 連続学習ストリーク**: 現在のストリーク日数（例: `5日連続達成！`）
3. **💬 AIコーチからの温かい一言**:
   - ユーザーのモチベーションを優しく高める労いメッセージ（例: 「お疲れ様でした！今日は昨日よりも集中して長く発話できましたね。英語のリズムが確実に身体に染み込んできています。明日もこのペースで楽しく進めていきましょう！」）
4. **🎯 今回の復習ポイント**:
   - 直近の練習で脱落・誤読した単語やリンキングのアドバイス（1〜2項目を箇条書きでシンプルに整理）。
5. **成果シェアボタン（3大SNS対応）**:
   - **𝕏（旧Twitter）**: Web Intent（`https://twitter.com/intent/tweet?text=...`）
   - **🧵 Threads**: Web Intent（`https://threads.net/intent/post?text=...`）
   - **📸 Instagram**:
     - スマホ: `navigator.share`（Web Share API）によるネイティブ共有シート起動
     - PC: クリップボードへシェアテキストをワンタップコピーし、Instagram Webを開く
6. **フッター**:
   - `[ ダッシュボードへ戻る ]` ボタン（`/` へ遷移）
   - モーダルを閉じる `[ 練習を続ける ]` リンク

## 4. 学習時間の計測ロジック

- 練習画面マウント時（または最初のフレーズ生成/録音開始時）に `sessionStartTimeRef.current = Date.now()` を記録。
- 「今日の学習を終了」タップ時に差分秒数を計算：
  ```typescript
  const elapsedSeconds = Math.max(60, Math.round((Date.now() - sessionStartTime) / 1000));
  const minutes = Math.floor(elapsedSeconds / 60);
  const seconds = elapsedSeconds % 60;
  const timeFormatted = `${minutes}分${seconds > 0 ? `${seconds}秒` : ""}`;
  ```
