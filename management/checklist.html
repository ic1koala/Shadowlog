1. プロダクト概要 ＆ バリュープロポジション

🎯 サービスビジョン

「英語を話したいすべての人が、挫折せず、圧倒的低価格で実践発話力を鍛えられるAIシャドーイング習慣化SaaS」

高額な人手添削（月2万円超）と発音修正のないフリートーク英会話の中間に位置する、最も効率的で安価な発話習熟トレーニングを提供。

⚡ コア差別化（独自の強み）
  • 即時Diff判定: Whisper文字起こしで脱落単語・誤読単語を瞬時に赤字可視化。
  • 話速（WPM）解析: ネイティブ音声に対する追従スピードを客観評価。
  • 弱点克服パーソナライズ: 苦手単語（Weak Words）を次回以降のAI生成文に自動注入。
  • 圧倒的低価格 ＆ 使い放題: 月額500円（Base）/ 1,480円（Pro）で回数無制限。

4. システムアーキテクチャ ＆ データベース設計

💻 技術スタック
  • Frontend: Next.js 14 (App Router), React 18, Tailwind CSS, Web Audio API
  • Backend: Vercel Serverless Edge, Node.js API Routes
  • Database / Auth: Supabase (PostgreSQL, Google OAuth / Email Auth, Row Level Security)
  • Payment: Stripe Billing / Checkout / Customer Portal
  • Email / CRM: Resend API (問い合わせ自動転送 & 自動返信)
  • SNS Tracking: Meta Graph API (Threads インサイト自動集計)
🗄️ Supabase データベーステーブル一覧
profiles: ユーザー基本情報 (id, email, plan, nickname, stripe_id)
user_tickets: チケット残数・日次利用カウンター (tickets_used, pro_trials_used)
practice_sessions: 練習履歴・スコア・WPM・Diff結果
weak_words: ユーザー別の苦手単語帳 (fail_count, is_mastered)
feedback_tickets: 不具合報告・問い合わせログ・添付スクショ
