## 1. プロダクト概要 & バリュープロポジション

### ① サービスビジョン
**「英語を話したいすべての人が、挫折せず、圧倒的低価格で実践発話力を鍛えられるAIシャドーイング習慣化SaaS」**

### ② 市場のペインと差別化
- **既存の課題**:
  - 人手による高額シャドーイング添削（シャドテン: 月額21,780円）は高価格すぎて大半のビジネスパーソンが継続できない。
  - フリートーク型AI英会話（Speak等）は、自分の発音のどこが落ちているか（脱落音・連結音）が可視化されにくい。
- **ShadowLogの解決策（2026/10/14 最新仕様）**:
  - **即時Diff判定 ＆ 太字青色チャンク（`/`）全ユーザー標準表示**: 発話音声をAI文字起こしし、脱落単語・誤読単語を赤字ハイライト（凡例は書き起こし直下に配置）。さらにレイアウトズレゼロの太字青色スラッシュ（`/`）で意味の塊（チャンク）を全ユーザー向けに標準可視化。
  - **3難易度レベルの TOEIC 500 / 700 / 850 厳格語彙換算（FB-049）**: 「初級で難しい単語が出る」問題を根絶するため、初級は最頻出2,000語（NGSL Level 1）に上限設定し、-tion/-ity等の抽象名詞を完全禁止。中級はTOEIC 700点（約4,000語）、上級はTOEIC 850点以上（約8,000語）に厳格キャリブレーション。さらにWhisper音声認識プロンプトを最適化し、口語縮約形（I'm, don't）の認識揺れ・不当減点を防止。
  - **3単語マイカスタム例文生成 ＆ 難易度連動1〜2文構成（FB-035）**: 「自分が今仕事や日常で使いたい3つの単語」を設定画面に登録し、練習画面からワンタップで即時オリジナル例文と音声を動的生成。初級（10〜14語）、中級（15〜20語）、上級（21〜28語）と無理のない自然な文脈構成で実践発話練習が可能（Base: 1日3回 / Pro: 1日10回）。
  - **Azure AI Speech 音素レベル発音評価エンジン ＆ 音響環境スマートメンション PoC（FB-046）**: 「適当な発音でも高得点が出る」Whisperの文脈忖度問題を克服するため、音素（Phoneme）波形照合エンジンを管理者テストモードへ導入。Accuracy, Fluency, Completeness, Prosody 4軸採点＋単語別Mispronunciation判定＋S/N比によるノイズ/マイク距離警告を実装。
  - **「今日の学習を終了する」ボタン ＆ セッション完了振り返りサマリー窓・SNSシェア（FB-047）**: 練習画面下部に終了ボタンを新設。学習時間、連続学習ストリーク、AIコーチ労いメッセージ、復習ポイントをまとめたモーダルを表示し、𝕏 / Threads / Instagram へ成果をワンタップシェア可能。
  - **思考整理・アプリ改善ロジックツリースタジオ（FB-050）**: 5大ブランチ（品質・UX・習慣化・コンテンツ・成長）のビジュアルツリー構造で、改善アイディアや技術論点を直感的に整理・保存・ダッシュボード連携。
  - **再生速度連動「動的WPM」リアルタイム表示**: お手本音声の再生速度（0.6x / 1.0x / 1.2x）ごとに、実測音声長（`duration`）と単語数から算出した実効WPMをリアルタイムでカプセルUIに併記表示。
  - **バックグラウンド1問先読み（Prefetch 0.0秒遷移）**: 1問目を練習中に裏側で次の問題と音声を先読みキャッシュし、画面下部オレンジ色の「次のフレーズへ」バーから待ち時間 `0.0秒` で連続練習可能。
  - **4大ジャンル×300文問題バンク（計3,600文）＆ 週10%季節・トレンド自動ローテーション**: 利用頻度の高い4ジャンル（`Tech`, `Business`, `Marketing`, `Daily`）×3レベル＝12スロットに各300文を蓄積。日常会話（Daily）での平易な口語ペルソナ分岐、季節感のオプショナル化、およびバズワード排除（FB-038）により、日常で本当に使われる自然な発話フレーズを徹底生成し、0.1秒配信とAPI原価70%超削減を両立。
  - **Listen-then-Speak 音響制御 ＆ 録音・採点ボタン最適化**: 録音開始時に再生中の模範音声を自動停止し、スピーカー音のマイク回り込み（誤採点）を完全防止。
  - **圧倒的低価格 & 使い放題**: 月額500円（Base）/ 月額1,000円（Pro：1,480円から改定）で1日回数上限なしの練習環境を提供。

## 8. スキマ特訓（Silent Mode）＆ Silent Drill 仕様 (FB-060)

### ① モード分離とボトムナビゲーション構成
外出先や満員電車、オフィスなど**「声を出せない環境」**でも学習を継続できるよう、下部ナビゲーションで役割を完全に分離する。

```
┌──────────────┬──────────────┬──────────────┬──────────────┐
│  📊 ダッシュ │   🎙️ 練 習   │  📖 スキマ   │   ⚙️ 設 定   │
│    ボード    │   (Active)   │     特訓     │              │
│              │              │   (Silent)   │              │
└──────────────┴──────────────┴──────────────┴──────────────┘
```
1. **ダッシュボード (`/`)**: 連続学習ストリーク、WPM推移グラフ、学習記録の確認。
2. **練習 (`/practice`) 〜 Active Mode**: 自宅・個室で声を出してシャドーイング（マイク録音・AI採点・Diff解析）。
3. **スキマ特訓 (`/review`) 〜 Silent Mode**: 電車・待ち時間で声を出さずに3〜4チャンクの語順パズル（Silent Drill）＆個人弱点カルテ。
4. **設定 (`/settings`)**: プラン管理、Web Pushリマインダー、アカウント情報。

### ② Silent Drill（弱点チャンクパズル）仕様
- **出題ロジック**: 過去のシャドーイングで噛んだ文・脱落した文（Diff履歴）から、AIが意味の塊（3〜4チャンク）を自動分割して出題。
- **操作性**: シャッフルされたチャンクブロックを親指タップ（1 ➔ 2 ➔ 3）で並べ替えるだけの片手操作。
- **Duolingoとの差別化**: 単語単位の文法クイズではなく、**「ネイティブの息継ぎ単位（チャンク）」で英語の語順通りに前から理解する「音速サイトトランスレーション」**の脳内トレーニング。

### ③ チケット消費とプラン別利用制限
- **チケット消費**: **完全ゼロ**（シャドーイングチケットは減らないため、スキマ時間に安心して開ける）。
- **無料版（Guest / Free）**: 1日10問（10例文）まで。
- **Baseプラン / Proプラン**: **無制限**で特訓可能。

### ④ 解放（アンロック）システム
- **アンロック条件**: 累計シャドーイングセッション **3回以上** 完了で自動解放。
- **未解放時**: 復習カルテ最上部に進捗バー（`◯ / 3回完了`）と案内を表示し、コールドスタート時の迷子を防止。

### ⑤ 有料プラン向け将来ロードマップ ＆ マイスクラップ実装 (FB-074)
- **Proプラン限定機能（Doc Shadow / マイスクラップ）**:
  - **統合入力（3モード）**:
    1. **🎬 YouTube（推奨・スマホ最適化）**: 共有リンク・動画IDから英語字幕を自動取得、タイムスタンプ解析からネイティブのリアル話速（WPM）を自動計測、GPT-4o-miniで3〜4文（45〜75語）のパッセージを自動生成。
    2. **🌐 Web記事URL**: 英語ニュースやブログのURLから本文を自動スクレイピング。
    3. **📄 PDF / テキスト**: 論文・資料からコピペした英文テキストを直接教材化。
  - **保存枠**: 同時最大5ソースまで登録可能（リストからワンクリックで練習・削除可能）。
  - **シームレス練習連携**: 練習画面（`/practice`）の長文（Passage）モードと直結し、TTSお手本音声・Whisperリアルタイム判定・WPM計測に対応。
- **今後の展開予定**:
  - **ダイアログ（対話形式）シャドーイング**: 2人の登場人物によるビジネスミーティング・英会話の掛け合いシャドーイング。
