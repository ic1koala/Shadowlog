## 1. 目的と概要
ユーザー定着率（リテンション）とサービスへの愛着を最大化するため、以下の2つのUI/機能改善を実施する：
1. **設定画面（`/settings`）**: 学習設定の上に「アカウント情報」セクションを新設（メール表示、ニックネーム登録、パスワード変更、Google連携表示）。
2. **ダッシュボード（`/`）**: 最上部に時間帯と登録ニックネームに応じた「パーソナライズ挨拶バナー」を新設。

---

## 2. 設定画面 UI仕様 (`src/app/(dashboard)/settings/page.tsx`)

### ① 配置場所
設定画面の最上部、既存の「学習分野・難易度設定」の上に新セクション「アカウント情報」として配置。

### ② 画面要素
1. **ニックネーム（表示名）設定**:
   - ラベル: **ニックネーム**
   - 説明: 「ダッシュボードの挨拶や学習レポートで使用されるあなたのお名前です。」
   - 入力欄: プレースホルダー「例: ヒデ、Alex」
   - 初期値:
     - Googleログイン時: Googleの登録名（`user.user_metadata.full_name` または `name`）を自動初期セット。
     - メアド登録時: 未設定時は空欄（保存時にバリデーション）。
   - 「保存」ボタン（または設定保存ボタンと連動）で Supabase `profiles.display_name` および LocalStorage（`shadowlog_nickname`）に保存。
2. **登録メールアドレス**:
   - ラベル: **メールアドレス**
   - 現在ログイン中のメールアドレス（`user.email`）を表示（読み取り専用）。
   - ゲスト（未ログイン）時: 「未登録（ゲスト体験中）」と表示し、`/login` への誘導ボタンを設置。
3. **パスワード ＆ パスワード変更**:
   - **Googleログインユーザーの場合**:
     - 「Googleアカウント連携中」バッジ（Gロゴアイコン付き）を表示。
     - 「Googleアカウントでログイン中のため、パスワードの変更は不要です。」と明記。
   - **メール/パスワードログインユーザーの場合**:
     - パスワード欄はセキュリティのため伏字（`••••••••`）で表示。
     - 「パスワードを変更する」ボタンを配置。
     - ボタンクリックでインライン展開またはモーダル表示：
       - 新しいパスワード入力欄（6文字以上）
       - 新しいパスワード（確認用）入力欄
       - 「変更を保存」ボタン ➔ `supabase.auth.updateUser({ password: newPassword })` を実行。成功時は「パスワードを変更しました」トースト表示。

## 3. ダッシュボード 挨拶バナー仕様 (`src/app/(dashboard)/page.tsx`)

### ① 配置場所
ダッシュボード（`src/app/(dashboard)/page.tsx`）の最上部（ヘッダー直下、統計カードの上）に配置。

### ② 時間帯別メッセージロジック（JST ローカル時間）
| 時間帯 | メッセージ本文 | アイコン/雰囲気 |
|---|---|---|
| **朝 (05:00 - 10:59)** | おはようございます、**{ニックネーム}さん**！<br />今日も爽やかに1フレーズから始めましょう☀️ | ☀️ 朝日 (bg-amber-500/10) |
| **昼 (11:00 - 16:59)** | こんにちは、**{ニックネーム}さん**！<br />午後のスキマ時間に英語でリフレッシュしませんか？☕ | ☕ カフェ (bg-blue-500/10) |
| **夜 (17:00 - 22:59)** | こんばんは、**{ニックネーム}さん**！<br />今日もお仕事お疲れ様でした。1日の終わりに少しだけ声を出してみましょう🌙 | 🌙 三日月 (bg-indigo-500/10) |
| **深夜 (23:00 - 04:59)** | こんばんは、**{ニックネーム}さん**。<br />遅くまで本当にお疲れ様です！無理のない範囲で練習してくださいね🦉 | 🦉 フクロウ (bg-purple-500/10) |

※ **ゲスト（未ログイン）時**:  
「こんにちは！今日もシャドーイングを始めましょう（残り体験チケット: {残り回数}回）」

## 4. データベース・ストレージ同期仕様

1. **Supabase `profiles` テーブル**:
   - `display_name TEXT` カラムを追加（未追加の場合はマイグレーションSQLを実行）：
     ```sql
     ALTER TABLE public.profiles ADD COLUMN IF NOT EXISTS display_name TEXT;
     ```
2. **ローカル永続化**:
   - `localStorage.getItem("shadowlog_nickname")` で即時レンダリングし、Supabaseから取得次第更新。
