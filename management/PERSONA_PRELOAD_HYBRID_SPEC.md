## 1. 意思決定の背景と課題

ユーザーが自身の職種や業界（例: 「化学系メーカー営業×半導体」など）を登録する「ペルソナ設定」を導入するにあたり、以下の技術的・事業的課題が存在していた：

1. **待ち時間（レイテンシ）の課題**:
   - 毎回スタートボタンを押した後にGPT-4o-miniで文を生成し、OpenAI TTSで音声を生成すると、**毎問2.0〜3.5秒のロード待機時間**が発生し、シャドーイングの軽快なテンポ感が損なわれる。
2. **API原価の青天井リスク**:
   - 熱心なユーザーが1日50問〜100問練習した場合、都度生成では月間API原価が1ユーザーあたり300円〜600円に膨らみ、Baseプラン（月500円）の利益が吹き飛ぶ。

### 採用方針：【アイデア3】事前バッチ先読みストックハイブリッド方式
上記課題を両立解決するため、**「アプリ起動時の非同期バックグラウンド生成（事前準備）」＋「日次ペルソナ枠消化後の既存ストック（問題バンク）シームレス移行」**を採択。

## 3. システムアーキテクチャ & シーケンス (アイデア3)

```mermaid
sequenceDiagram
    autonumber
    actor User as ユーザー
    participant App as クライアント (PWA/Web)
    participant Cache as ローカルキャッシュ (IndexedDB)
    participant API as バックエンド (/api/persona/preload)
    participant DB as 既存問題バンク (3,600問ストック)

    Note over User,App: アプリ起動時 (Dashboardマウント)
    App->>API: ① バックグラウンド事前取得リクエスト (当日未消化分: Base 5問 / Pro 15問)
    API->>Cache: ② 当日分が既に生成済みか確認
    alt 未生成の場合
        API-->>API: GPT-4o-mini (ペルソナ文) + TTS 音声一括生成
        API->>Cache: ③ キャッシュ保存 (IndexedDB)
    end

    Note over User,App: ユーザーが「練習スタート」をタップ
    User->>App: 「シャドーイング開始」
    App->>Cache: ④ プリロード済みペルソナ問題を取得
    Cache-->>App: 即時返却 (待機時間 0.0秒!)
    App-->>User: 1問目スタート (待ち時間なし)

    Note over User,App: 当日クォータ (5問 / 15問) 完了後
    User->>App: 「次の問題へ」 (6問目 or 16問目)
    App->>DB: ⑤ 学習設定カテゴリ (Tech/Business/Marketing/Daily) のストック取得
    DB-->>App: 即時返却 (API原価 0円 / 待機時間 0.0秒)
    App-->>User: ストック出題へシームレス移行 (無制限練習可能)
```

### 3.1. プリロードのタイミングと最適化
1. **トリガー**: アプリの起動（Dashboard画面マウント時）。
2. **非同期実行**: 画面描画や操作を一切ブロックしない（バックグラウンドワーカーまたは`useEffect`内の非同期フェッチ）。
3. **即時スタート保証**: ユーザーが起動後1秒以内に「スタート」を押した場合でも、配列のインデックス0（1問目）から順次ストリーミング受信・解決するため、待たされることはない。

## 4. 収益性・コスト試算 (ユニットエコノミクス)

### 4.1. 動的生成の単価前提
- 1問あたりのテキスト生成 (GPT-4o-mini): 約 ¥0.034
- 1問あたりの音声合成 (OpenAI TTS-1 / 約15〜20語): 約 ¥0.140
- **1問合計動的生成原価**: **約 ¥0.174 / 問**
- 既存ストック問題（問題バンク）の出題原価: **¥0.000 / 問**

### 4.2. プラン別月間原価上限と粗利
| プラン | 月額会費 | 月間ペルソナ生成原価上限 | 月間粗利益 | 粗利益率 |
| :--- | :--- | :--- | :--- | :--- |
| **Base (500円)** | ¥482 (Stripe差引後) | 最大 ¥26.1 (5問×30日×0.174円)<br>※平均受講 ¥15.7 (3問/日想定) | **約 ¥410 〜 ¥456** | **85.1% 〜 94.6%** |
| **Pro (1,000円)** | ¥964 (Stripe差引後) | 最大 ¥78.3 (15問×30日×0.174円)<br>※平均受講 ¥41.8 (8問/日想定) | **約 ¥805 〜 ¥922** | **83.5% 〜 95.6%** |

> [!IMPORTANT]
> **原価防御のポイント**:
> ユーザーが1日に100問練習しても、5問（Proは15問）を超えた分はすべて出題原価0円の「3,600問ストック」から配信されるため、**1ユーザーあたりの月間AI原価が絶対に26.1円（Proは78.3円）を超えない**設計となっています。
