## 1. 目的と背景

- **課題**: 現行の「音声を聴き終わってから喋る」フローは正確には「リピーティング」であり、本来の「シャドーイング（音声を耳で聴きながら同時に影のように発話する）」とは異なっていた。
- **解決策**:
  - 一般ユーザーやVIPテスターへの影響をゼロにするため、まずは**管理者テストモード（`isAdminEmail(userEmail)`）限定**で実装する。
  - 従来の方式を**「リピーティング録音」**として左側に配置。
  - お手本音声を同時に流しながらイヤホンで聴いて録音する新方式を**「シャドーイング録音」**として右側に配置。
  - イヤホン装着前提の音響制御（`echoCancellation: false`）により、再生音が小さくなるダッキング現象とマイク回り込みを防止し、安定したAI判定を実現する。

## 2. UIデザイン & ボタン配置要件

### 2.1 表示切り替え条件（管理者限定）
- `isAdminEmail(userEmail)` が `true` の場合:
  - 画面下部フローティング録音バー（および `AudioRecorder.tsx` 内の表示）で、録音ボタンが**左右2分割**のボタングループになる。
  - バー上部に小さく `🧪 管理者テスト: 録音方式検証中` のバッジを表示。
- 一般ユーザー / 非管理者の場合:
  - 従来通りの単一ボタン（「シャドーイングを開始」または「録音を開始」）を表示し、1ピクセルも変更なし。

### 2.2 ボタングループの配置（待機状態 `!isRecording`）

│ 🧪 管理者テスト: 録音方式検証中                                   │

│                                                                 │
│  ┌───────────────────────┐   ┌───────────────────────────────┐  │

#### 左ボタン: 【🗣️ リピーティング録音】
- **スタイル**: `bg-secondary text-secondary-foreground hover:bg-secondary/80`
- **ラベル**:
  - メイン: `🗣️ リピーティング録音`
  - サブ（小文字）: `(お手本停止・自習)`
- **挙動**: 従来と同じ。お手本音声を強制停止し、マイクのみ起動。

#### 右ボタン: 【🎧 シャドーイング録音】
- **スタイル**: `bg-blue-600 text-white shadow-md hover:bg-blue-500`
- **ラベル**:
  - メイン: `🎧 シャドーイング録音`
  - サブ（小文字）: `(イヤホンを装着してください)`（`text-[10px] opacity-90 block`）
- **挙動**:
  1. タップすると、マイク録音を開始すると同時に、`SentenceCard` の模範音声を再生開始（シンクロスタート）。
  2. 模範音声終了後、シャドーイングの遅れマージン（約1.5秒）を待機して自動で録音停止 ➔ 差分解析へ送信（途中停止も可能）。

## 3. 音響制御 & 内部連携ロジック

### 3.1 模範音声の強制停止バイパス
- 現在の `SentenceCard.tsx` の `useEffect` で `isRecording` 時に `stopModelAudio()` を呼んでいる箇所を改修。
- 録音種別 `recordingType: "repeating" | "shadowing"` をコンテキストまたはイベントで管理。
  - `repeating`: 従来通り `stopModelAudio()` を実行。
  - `shadowing`: `stopModelAudio()` を実行せず、むしろ模範音声を即座に再生（`playModelAudio()`）する。

### 3.2 ダッキング防止（`echoCancellation: false`）
- `src/hooks/use-audio-recorder.ts`:
  - `startRecording(mode?: "repeating" | "shadowing")` 引数を追加。
  - `shadowing` モードで録音開始する場合:
    ```typescript
    const constraints: MediaTrackConstraints = {
      deviceId: selectedDeviceId ? { ideal: selectedDeviceId } : undefined,
      echoCancellation: false, // イヤホン前提のためAECをOFFにし、再生音のダッキング（減衰）を防止！
      noiseSuppression: true,
      autoGainControl: true,
    };
    ```

### 3.3 自動録音停止タイマー
- シャドーイング録音時、模範音声の `audio.onended` イベント（または計算上の再生秒数 + 1.5秒）をトリガーに、自動的に `stopRecording()` を呼び出して解析へ進める。

## 4. 検証・品質要件

1. `isAdminEmail` による管理者・一般ユーザーの確実なUI分離（一般ユーザー画面で崩れや変更がないこと）。
2. リピーティング録音：従来の動作と100%同一であること。
3. シャドーイング録音：
   - イヤホンを接続した状態で、お手本音声がクリアに聞こえ続け（ダッキングなし）、発声した自分の声のみがWhisperに送信されること。
   - 模範音声の終了＋1.5秒で自動停止すること。
4. `npm run type-check`、`npx vitest run`、`npm run build` がすべて合格すること。
