## 3. 音響制御 & 内部連携ロジック

### 3.1 模範音声の強制停止バイパス
- 現在の `SentenceCard.tsx` の `useEffect` で `isRecording` 時に `stopModelAudio()` を呼んでいる箇所を改修。
- 録音種別 `recordingType: "repeating" | "shadowing"` をコンテキストまたはイベントで管理。
  - `repeating`: 従来通り `stopModelAudio()` を実行。
  - `shadowing`: `stopModelAudio()` を実行せず、むしろ模範音声を即座に再生（`playModelAudio()`）する。

### 3.2 ダッキング防止（`echoCancellation: false`）
- `src/hooks/use-audio-recorder.ts`:
  - `startRecording(mode?: "repeating" | "shadowing")` 引数を追加。
  - `shadowing` モードで録音開始する場合:
    ```typescript
    const constraints: MediaTrackConstraints = {
      deviceId: selectedDeviceId ? { ideal: selectedDeviceId } : undefined,
      echoCancellation: false, // イヤホン前提のためAECをOFFにし、再生音のダッキング（減衰）を防止！
      noiseSuppression: true,
      autoGainControl: true,
    };
    ```

### 3.3 自動録音停止タイマー
- シャドーイング録音時、模範音声の `audio.onended` イベント（または計算上の再生秒数 + 1.5秒）をトリガーに、自動的に `stopRecording()` を呼び出して解析へ進める。

## 4. 検証・品質要件

1. `isAdminEmail` による管理者・一般ユーザーの確実なUI分離（一般ユーザー画面で崩れや変更がないこと）。

   - イヤホンを接続した状態で、お手本音声がクリアに聞こえ続け（ダッキングなし）、発声した自分の声のみがWhisperに送信されること。
   - 模範音声の終了＋1.5秒で自動停止すること。
4. `npm run type-check`、`npx vitest run`、`npm run build` がすべて合格すること。
