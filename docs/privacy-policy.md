# ShadowLog プライバシーポリシー

ShadowLog（以下「当方」といいます。）は、英語シャドーイング学習Webサービス「ShadowLog」（以下「本サービス」といいます。）におけるユーザーの個人情報およびプライバシー情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。

---

## 第1条（基本方針）
当方は、個人情報の重要性を認識し、個人情報の保護に関する法律（以下「個人情報保護法」といいます。）その他の関係法令を遵守するとともに、適切な取得・利用・管理に努めます。

## 第2条（収集する情報および取得方法）
本サービスにおいて、当方は以下の情報を取得・収集します。

1. **ユーザーから直接ご提供いただく情報**
   - アカウント情報：メールアドレス、パスワード（暗号化の上保管）、ユーザー識別ID等
   - プロフィール・属性情報：業種、関心分野、目標レベル等の英語学習カスタマイズ用設定情報
2. **本サービスの利用にあたり取得・処理する情報**
   - **音声データ**：本サービス上でマイクを通じて録音されたユーザーの発話音声データ
   - **テキストデータ**：AIが自動生成した例文、音声文字起こし結果、発話Diff（差分）解析結果
   - **学習ログ・統計データ**：発話単語数、練習回数、連続学習日数（ストリーク）、アクティビティ履歴
   - **決済情報**：有料プランの購入履歴、契約プラン（※クレジットカード番号等の決済情報は決済代行会社であるStripe Inc.が直接処理し、当方のサーバーには保管されません）
3. **本サービスアクセス時に自動的に取得する情報**
   - アクセスログ（IPアドレス、アクセス日時、リファラー情報）
   - クッキー（Cookie）およびローカルストレージ情報
   - 端末情報、OS、ブラウザの種類およびバージョン

## 第3条（利用目的）
当方は、収集した情報を以下の目的で利用します。

1. **本サービスの提供および本人確認**
   - アカウント登録の受付、ログイン認証、本人確認
   - ユーザーの属性に応じた英語例文のAI生成および模範音声の提供
   - 音声の文字起こし、発話Diffの計算・可視化、学習ログのダッシュボード表示
2. **有料サービスの決済および管理**
   - 有料プランの請求管理、決済処理、自動更新の確認
3. **サービスの改善・開発・不具合対応**
   - システムの運用・保守・エラー調査・セキュリティ対策
   - ユーザー体験の向上、新機能の開発、サービス性能の最適化
   - 匿名化・統計化されたデータに基づく利用動向の分析
4. **ユーザーサポートおよび連絡**
   - お問い合わせ対応、規約違反行為への対応、重要なお知らせの通知

## 第4条（第三者APIサービスへのデータ提供・委託）
本サービスは、高度な機能提供のために外部のAPIサービスを利用しています。ユーザーは、本サービスの利用にあたり、以下のデータが第三者に送信・処理されることに同意するものとします。

1. **OpenAI Inc. へのデータ送信**
   - **送信するデータ**：ユーザーの発話音声データ、テキストデータ
   - **送信の目的**：OpenAI APIを通じた英文自動生成、音声合成（TTS）、および音声文字起こし（Whisper API）の実施
   - **データの取扱いについて**：OpenAIのAPI利用規約に基づき、API経由で送信されたデータは、OpenAI側のAIモデルの学習（Training）には利用されません。
2. **インフラおよびクラウドサービス事業者への委託**
   - 当方は、本サービスのホスティング、データベース運用、ユーザー認証、決済処理等のため、適切な安全管理措置を講じている事業者（Vercel Inc., Supabase Inc., Stripe Inc.等）にデータの保管・処理を委託しています。

## 第5条（個人情報の第三者提供）
当方は、以下の場合を除き、ユーザーの同意を得ることなく第三者に個人情報を提供することはありません。
1. 法令に基づく場合
2. 人の生命、身体または財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき
3. 公衆衛生の向上または児童の健全な育成の推進のために特に必要がある場合であって、本人の同意を得ることが困難であるとき
4. 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合であって、本人の同意を得ることにより当該事務の遂行に支障を及ぼすおそれがあるとき
5. サービスの合併、事業譲渡その他の事由による事業の承継に伴って個人情報が提供される場合

## 第6条（安全管理措置）
当方は、個人情報の漏洩、滅失または毀損の防止その他の個人情報の安全管理のために、以下の適切な措置を講じます。
1. 通信の暗号化（SSL/TLS）による安全なデータ伝送
2. データベースへのアクセスコントロール（Supabase Row Level Security等による本人以外のアクセス遮断）
3. 外部APImによる認証情報の厳重管理およびアクセス権限の制限
4. 一時的な音声ファイルの適切な削除管理

## 第7条（Cookieおよびアクセス解析ツール）
1. 本サービスでは、ユーザーの利便性向上、ログイン状態の維持、および利用状況の把握のためにCookieおよび類似技術（Web Storage等）を使用しています。
2. ユーザーは、ブラウザの設定を変更することによりCookieの受入を拒否することができますが、その場合、本サービスの一部機能が利用できなくなる場合があります。

## 第8条（個人情報の開示・訂正・削除・利用停止）
1. ユーザーは、本サービスのアカウント設定画面等を通じて、自身の登録情報を確認・訂正することができます。
2. ユーザーが退会（アカウント削除）を希望する場合、当方が定める手続きに従いアカウントを削除することができます。アカウント削除後、当方は遅滞なくユーザーの個人情報を消去または匿名化処理します。ただし、法令に基づく保管義務がある情報についてはこの限りではありません。
3. ユーザーは、当方に対し、個人情報保護法の定めに従い自身の個人情報の開示、訂正、追加、削除、利用停止を請求することができます。

## 第9条（プライバシーポリシーの改定）
1. 当方は、法令の変更、本サービスの内容変更、または運営方針の見直し等に伴い、本ポリシーを適宜見直し、改定することがあります。
2. 改定後の本ポリシーは、本サービス上に掲載した時点、または当方が定める効力発生日から効力を生じるものとします。重大な変更がある場合は、サービス上での掲示等適切な方法でお知らせします。
