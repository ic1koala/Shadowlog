# ShadowLog 利用規約

本利用規約（以下「本規約」といいます。）は、ShadowLog（以下「本サービス」とい me ます。）の提供条件および本サービスの利用に関する運営者（以下「当方」といいます。）とユーザーの皆様（以下「ユーザー」といいます。）との間の権利義務関係を定めるものです。

本サービスの利用に際しては、本規約の全文をお読みいただいた上で、本規約に同意いただく必要があります。

## 第1条（適用）
1. 本規約は、ユーザーと当方との間の本サービスの利用に関わる一切の関係に適用されます。
2. 当方が本サービス上で掲載する本サービスの利用に関するルール、ヘルプ、注意事項等（以下「個別規定」といいます。）は、本規約の一部を構成するものとします。本規約と個別規定の内容が異なる場合は、個別規定が優先して適用されます。

## 第2条（定義）
本規約において使用する用語の定義は、以下のとおりとします。
1. **「本サービス」**: 当方が提供する英語シャドーイング学習Webサービス「ShadowLog」（理由の如何を問わずサービスの名称または内容が変更された場合は、当該変更後のサービスを含みます）を指します。
2. **「ユーザー」**: 本規約に同意の上、本サービスの利用登録を行った個人または法人を指します。
3. **「AI生成コンテンツ」**: 本サービス内で人工知能（AI）技術を用いて自動生成される英文、日本語訳、音声等のコンテンツを指します。
4. **「発話データ」**: ユーザーが本サービスの利用にあたりマイク等を通じて録音・送信した音声データおよびこれを文字起こししたテキストデータを指します。

## 第3条（アカウント登録および管理）
1. 本サービスの利用を希望する者（以下「登録希望者」といいます。）は、本規約を遵守することに同意し、当方の定める方法に従い登録情報を当方に提供することにより、利用登録を申請することができます。
2. 登録希望者は、自己の責任において、正確かつ最新の情報を登録するものとします。
3. ユーザーは、自己の責任において本サービスのアカウント情報（メールアドレス、パスワード等）を厳重に管理するものとします。
4. ユーザーは、いかなる場合もアカウントを第三者に譲渡、貸与、または共用することはできません。当方は、登録されたアカウント情報を用いて行われた本サービスの利用を、すべて当該アカウントを所有するユーザー本人による利用とみなします。

1. ユーザーは、有料サービス（月額サブスクリプションまたは従量課金等）を利用する場合、当方が別途定め、本サービス上に表示する利用料金を、当方が指定する決済方法（Stripe等の決済代行サービス）により支払うものとします。
2. **自動更新**: 有料サブスクリプションプランは、ユーザーが当方の定める方法により更新解約手続きを行わない限り、従前の契約期間満了時に自動的に同期間延長（更新）されるものとし、ユーザーはこれに同意します。
3. **利用料金の変更（価格改定）**: 当方は、当方の判断により、有料サービスの利用料金を変更（値上げまたは値下げを含む価格改定）することができるものとします。利用料金を変更する場合、当方は変更後の料金および変更の効力発生日を、本サービス上での掲示または電子メール等の適切な方法により、事前に（相当な予告期間を設けて）ユーザーに通知または周知します。変更後の料金に同意いただけないユーザーは、効力発生日までに有料プランの解約手続きを行うものとし、効力発生日以降にユーザーが本サービスを継続して利用した場合、変更後の利用料金に同意したものとみなします。
4. **解約**: ユーザーは、いつでも有料プランの解約手続きを行うことができます。解約手続きが完了した場合でも、すでに支払われた有効期間終了までは引き続きサービスを利用することができます。
5. **返金ポリシー**: サービスの性質上、すでに支払われた利用料金の返金、および日割り計算による減額・返金は一切行わないものとします。ただし、当方の責めに帰すべき事由によりサービスが全く提供されなかった場合、または法令により返金が義務付けられている場合はこの限りではありません。
