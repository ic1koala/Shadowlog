# ShadowLog AIコスト・収益試算シミュレーター

本フォルダ（`AI cost/`）には、OpenAI API（GPT-4o-mini / TTS-1 / Whisper-1）の**実測消費実績**に基づいたコスト試算プログラムおよびインタラクティブWebダッシュボードが格納されています。

---

## 1. 含まれるツール

1. **`simulation.py` (CLIプログラム)**:
   - ターミナルから引数を指定して即座に試算レポートを表示できます。
   ```bash
   # デフォルト実行（50人 × 毎日50回 × 月額300円）
   python3 "AI cost/simulation.py"

   # 条件を変えて実行（例: 100人、毎日15回、月額500円）
   python3 "AI cost/simulation.py" --users 100 --daily-uses 15 --price 500
   ```

2. **`index.html` (GUIシミュレーター)**:
   - スライダーを動かして「人数」「利用頻度」「月額料金」「為替」をリアルタイムにシミュレーションできます。
   - ブラウザでダブルクリックして開くか、Macターミナルから以下で起動できます：
   ```bash
   open "AI cost/index.html"
   ```

## 2. 実績データに基づく1回あたりの原価内訳

添付いただいたOpenAI Usageダッシュボードの実測データから算出した、練習1回あたりの厳密な原価です（1ドル = 150円想定）。

| API機能 | 実績指標 | 公式料金 | 1回あたり原価 (USD) | 1回あたり原価 (JPY) | コスト構成比 |
|---|---|---|---|---|---|
| **TTS-1** (模範音声) | 1文 約133文字 | $15.00 / 100万文字 | **$0.00200** | **0.299 円** | **62.5%** |
| **Whisper-1** (発話認識) | 録音 約10秒 | $0.006 / 分 | **$0.00099** | **0.149 円** | **31.1%** |
| **GPT-4o-mini** (文生成+コーチ) | 合計 約570トークン | In $0.15 / Out $0.60 | **$0.00021** | **0.031 円** | **6.4%** |
| **合計 (1回のフル練習)** | — | — | **$0.00319** | **約 0.48 円** | **100%** |

> **ポイント**: コストの **6割以上をTTS-1（音声読み上げ）** が占めており、テキスト生成のGPT-4o-miniはわずか6%と極めて安価です。

## 3. ご指定条件での収支試算（50人 × 毎日50回 × 月額300円）

### ① 試算サマリー
- **月間総売上** : 50人 × 300円 = **15,000 円**
- **クレカ決済手数料 (3.6%)** : -**540 円** (手取: 14,460 円)
- **月間総練習回数** : 50人 × 50回 × 30日 = **75,000 回 / 月**
- **月間AI総原価** : 75,000回 × 0.479円 = **35,929 円** ($239.53)
- **月間最終損益 (粗利)** : 🔴 **-21,469 円 (大赤字 / 利益率 -143%)**

### ② なぜ赤字になるのか？
- 毎日50回（月1,500回）練習するユーザーの**1人あたりAI原価は毎月 719 円** に達します。
- これに対し、月額料金が **300 円** だと、**ユーザーが使えば使うほど毎月 1人あたり約 429 円の赤字** が発生してしまいます。

## 4. 収益化・黒字化のための4大戦略

### 提案A: 月額300円プランは「1日15〜20回まで」の上限を設ける（おすすめ）
- 月額300円での損益分岐点は **1日 20.1回（月 604回）** です。
- 「月額300円: 1日15回まで練習可能（毎日15分相当）」と上限を設けることで、1人あたり約 74 円（粗利率25%）の黒字を確実に確保できます。

### 提案B: 毎日50回ガチ練習できる「無制限Proプラン」を月額 1,480 円にする
- 毎日50回練習（月1,500回）するユーザーは、英語学習サービスとしては超ヘビーユーザーです。
- 月額 1,480 円（税抜）に設定すれば、原価719円・決済手数料を引いても **1人あたり毎月 +700 円超（粗利率 約50%）の健全な利益** が出ます。
- 他社（シャドテン月額2万円、ELSA月額2,000円等）と比較しても、月額1,480円は依然として圧倒的な安さで競争力があります。

### 提案C: 2段階プラン制（ハイブリッド）
- **エントリープラン (月額 300 円)**: 1日 10回まで練習可能（ライト・継続重視）
- **無制限Proプラン (月額 980 円 〜 1,480 円)**: 1日 無制限＋長文スピーチモード使い放題

### 提案D: 模範音声キャッシュによる原価60%削減（技術的対策）
- 最大の原価要因である TTS-1（0.3円/回）について、すでに一度生成された英文やプリセット文の音声を Supabase Storage にキャッシュすれば、2回目以降の再生コストは **0円** になります。
- 復習やリトライが多いユーザーほど原価が **0.18円/回** まで劇的に圧縮されます。
