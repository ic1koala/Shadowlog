# ShadowLog AIコスト・収益試算シミュレーター

本フォルダ（`AI cost/`）には、OpenAI API（GPT-4o-mini / TTS-1 / Whisper-1）の**実測消費実績**および**アプリ仕様改善（手動生成化＋リトライ時TTS再利用）**を反映した最新のコスト試算ツール群が格納されています。

今後、事業推進や価格改定、ユーザー規模拡大時の収支管理はこのツール群を中心に行います。

---

## 1. 含まれるツール

1. **`index.html` (GUIシミュレーター・管理画面)**:
   - スライダーを動かして「有料会員数」「1日平均利用回数」「月額料金」「為替」をリアルタイムにシミュレーションできます。
   - アプリ仕様改善モード（通常0.48円 → 改善後0.32円 → 高度キャッシュ0.18円）のワンクリック切り替え対応。
   - ブラウザでダブルクリックして開くか、Macターミナルから以下で起動できます：
   ```bash
   open "AI cost/index.html"
   ```
   ※ Next.js開発サーバー起動時は `http://localhost:3000/simulation.html` または `http://localhost:3000/management.html` からも直接利用できます。

2. **`simulation.py` (CLIプログラム)**:
   - ターミナルから即座に引数を指定して詳細な収支レポートを出力できます。
   ```bash
   # デフォルト実行（50人 × 毎日20回 × 月額500円 [アプリ改善版0.32円/回]）
   python3 "AI cost/simulation.py"

   # Proプラン実行（50人 × 毎日40回 × 月額1,480円）
   python3 "AI cost/simulation.py" --price 1480 --daily-uses 40

   # スケール時実行（200人 × 毎日20回 × 月額500円）
   python3 "AI cost/simulation.py" --users 200 --daily-uses 20 --price 500
   ```

## 2. 実績データに基づく1回あたりの原価内訳（アプリ仕様変更の反映）

| API機能 | 実績指標 | 公式料金 | 1回あたり原価 (USD) | 1回あたり原価 (JPY) | コスト構成比 |
|---|---|---|---|---|---|

| **Whisper-1** (発話認識) | 録音 約10秒 | $0.006 / 分 | **$0.00099** | **0.149 円** | **31.1%** |
| **GPT-4o-mini** (文生成+コーチ) | 合計 約570トークン | In $0.15 / Out $0.60 | **$0.00021** | **0.031 円** | **6.4%** |
| **合計 (従来フル実行)** | — | — | **$0.00319** | **約 0.479 円** | **100%** |

### ② アプリ仕様改善後（手動生成化 ＋ リトライ時TTS再利用）: 約 0.32 円 / 回 【約31%圧縮】
- **手動フレーズ生成**: 画面表示ごとの自動生成廃止により、無駄なAPI呼び出しをゼロ化。
- **同一フレーズでの複数回リトライ**: ユーザーは1フレーズにつき平均2回発話練習を実施。その際、TTS音声（base64）はメモリ上で再利用されるため、リトライ発話時のTTSコストは **0円**。
- **実質1練習あたり原価**:
  - TTS-1: 約 **0.150 円**（半減）
  - Whisper-1: 約 **0.149 円**
  - GPT-4o-mini: 約 **0.023 円**
  - **合計実質原価**: **約 0.322 円 / 回** ($0.00214)

## 3. 最新条件での収支試算（ベース500円 / Pro 1,480円 / 初期20回）

### 【プランA】ベースプラン（50名 × 1日20回 × 月額500円）
- **月間総売上** : 50人 × 500円 = **25,000 円**
- **クレカ決済手数料 (3.6%)** : -**900 円** (手取: 24,100 円)
- **月間総練習回数** : 50人 × 20回 × 30日 = **30,000 回 / 月**
- **月間AI総原価** : 30,000回 × 0.322円 = **9,649 円** ($64.33)
- **1人あたり月間AI原価** : **193 円 / 人**
- **月間最終損益 (粗利)** : 🟢 **+14,451 円 (粗利率 57.8%)**
- **1人あたり月間粗利** : **+289 円 / 人**

> **結論**: アプリ仕様改善と1日20回の初期設定により、**月額500円でも粗利率57%以上の強固な黒字基盤**が確立されています。

---

### 【プランB】Proプラン（50名 × 1日40回 × 月額1,480円）
- **月間総売上** : 50人 × 1,480円 = **74,000 円**
- **クレカ決済手数料 (3.6%)** : -**2,664 円** (手取: 71,336 円)
- **月間総練習回数** : 50人 × 40回 × 30日 = **60,000 回 / 月**
- **月間AI総原価** : 60,000回 × 0.322円 = **19,298 円** ($128.65)
- **1人あたり月間AI原価** : **386 円 / 人**
- **月間最終損益 (粗利)** : 🟢 **+52,038 円 (粗利率 70.3%)**
- **1人あたり月間粗利** : **+1,041 円 / 人**

> **結論**: Proプラン（月額1,480円）は、ユーザーが毎日40〜50回ガチ練習しても原価は約400円前後に収まり、**粗利率70%（1人粗利1,000円超）の高LTVエンジン**となります。
