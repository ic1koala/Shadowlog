# ShadowLog 総合収支試算シミュレーター（問題バンク＆GMO固定費連動版）

**最終更新日**: 2026年9月30日  

本フォルダ（`AI cost/`）には、OpenAI API（GPT-4o-mini / TTS-1 / Whisper-1）の**実測消費実績**、**4大ジャンル×300文問題バンク（`sentence_bank`）＋週1回10%自動ローテーション＋先読み（Prefetch）仕様**、および**GMOオフィスサポート（バーチャルオフィス固定費）**を反映した最新の事業収支シミュレーターが格納されています。

---

## 1. 含まれるツール

1. **`index.html` (GUIシミュレーター・管理画面 / `public/simulation.html` と同期)**:
   - スライダーを動かして「有料会員数」「1日平均利用回数」「月額料金（ARPU）」「為替」「固定費（GMO代）」「API計算モード（バンク定常期 / 蓄積期 / 従来）」をリアルタイムにシミュレーションできます。
   - ブラウザで開くか、Macターミナルから以下で起動できます：
   ```bash
   open "AI cost/index.html"
   ```
   ※ Next.js開発サーバー起動時は `http://localhost:3000/simulation.html` または `http://localhost:3000/management.html` からも直接利用できます。

2. **`simulation.py` (CLIプログラム)**:
   - ターミナルから即座に引数を指定して詳細な2フェーズ収支レポートを出力できます。
   ```bash
   # デフォルト実行（バンク定常運用モード + 50名ポートフォリオ試算 + GMO代1,650円込）
   python3 "AI cost/simulation.py"

   # 蓄積期（保守上限 @0.322円/回）モードでの実行
   python3 "AI cost/simulation.py" --mode accumulation

   # Proプラン単体実行（50人 × 毎日40回 × 月額1,480円）
   python3 "AI cost/simulation.py" --price 1480 --daily-uses 40
   ```
