# ShadowLog 総合収支試算シミュレーター（2026/10/06 最新仕様・問題バンク＆3単語カスタム生成＆GMO固定費連動版）

**最終更新日**: 2026年10月6日（FB-022〜FB-039 最新仕様反映済）  

本フォルダ（`AI cost/`）には、OpenAI API（GPT-4o-mini / TTS-1 / Whisper-1）の**実測消費実績**、**4大ジャンル×300文問題バンク（`sentence_bank`）＋週1回10%自動ローテーション＋先読み（Prefetch）仕様**、**3単語カスタム例文生成（`FB-035`）**、**クライアント完結型ゼロコスト最適化群（`FB-022〜039`）**、および**GMOオフィスサポート（バーチャルオフィス固定費）**を反映した最新の事業収支シミュレーターが格納されています。

## 1. 含まれるツール

1. **`index.html` (GUIシミュレーター・管理画面 / `public/simulation.html` と完全同期)**:
   - スライダーとセレクターを動かして「有料会員数」「1日平均利用回数」「月額料金（ARPU）」「為替」「固定費（GMO代）」「API計算モード（バンク定常期 / 蓄積期 / 従来）」「✨ 3単語カスタム生成枠の利用想定（実効平均 / 毎日上限フル / なし）」をリアルタイムにシミュレーションできます。
   - ブラウザで開くか、Next.js開発サーバー起動時は `http://localhost:3000/simulation.html` または `http://localhost:3000/management.html` から直接利用できます。

2. **`simulation.py` (CLIプログラム)**:
   - ターミナルから引数を指定して詳細な収支レポートを出力できます。
   ```bash
   # デフォルト実行（バンク定常運用 + 3単語カスタム実効平均 + 50名ポートフォリオ + GMO代1,650円込）
   python3 "AI cost/simulation.py"

   # 3単語カスタム生成を「全員毎日上限フル利用（Base 3回/日・Pro 10回/日）」で実行
   python3 "AI cost/simulation.py" --custom-words max

   # 蓄積期（保守上限 @0.322円/回）モードでの実行
   python3 "AI cost/simulation.py" --mode accumulation
   ```
