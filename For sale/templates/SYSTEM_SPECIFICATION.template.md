## 4. システムアーキテクチャ & 技術スタック

```
[クライアント (Web / PWA / モバイル)]
        │
        ▼ (HTTPS)
[Next.js App Router (Vercel Edge / Serverless)]
        │
        ├────────────────────────┬────────────────────────┐
        ▼                        ▼                        ▼
[Supabase (Auth / PostgreSQL)]  [Stripe (決済 / Portal)]  [外部LLM / API基盤]
```

### ① 技術スタック
- **Frontend**: Next.js (App Router), React, TypeScript, Tailwind CSS
- **Backend / Hosting**: Vercel Serverless Functions
- **Database / Auth**: Supabase (PostgreSQL, Row Level Security)
- **Payment**: Stripe Billing / Checkout / Customer Portal
- **Email / CRM**: Resend API (自動通知・返信)

### ② 主要データベーステーブル設計 (Supabase)
- `profiles`: ユーザー基本情報 (id, email, plan, display_name, stripe_customer_id)
- `user_tickets`: 利用チケット残数・日次カウンター
- `user_sessions`: サービスの実行履歴・スコア・結果データ
- `user_bookmarks`: 苦手項目やお気に入りリスト
- `feedback_tickets`: 問い合わせ・不具合報告ログ

## 5. 管理・運用・モニタリング体制

### ① 顧客管理ダッシュボード (`/admin/customers` 等)
- **利用モニタリング**: 全ユーザーの本日の利用数、1日平均利用数を集計。
- **採算リスク自動計算**: 1回原価をもとに月間想定原価と損益分岐点に対するリスクステータス（🟢安全 / 🟡注意 / 🔴警戒）を自動判定。

### ② お問い合わせ対応窓口
- アプリ内フォームから送信された問い合わせが管理者のメールへ即時HTML通知され、ワンクリックで直接返信可能。
